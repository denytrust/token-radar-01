    Honest limits — read before you farm

    1. The value model is weak in absolute terms. R² 0.145; typical miss ×3.26 leave-one-out, ×4.98 blind holdout. mcap/TVL spans 8 orders of magnitude; no snapshot variable explains more.
    2. The P25–P75 interval is not evenly honest by size: 67% coverage for small protocols, 43% for mid-size, 50% for large. A heteroskedastic interval was tried and did not fix it.
    3. The sensor correction rests on one untestable assumption. In one snapshot, age and cohort are the same variable. v4 reads the age gradient as a calendar cliff (May 2024): pre-2024 cohorts list at ~0.78, post-2024 at ~0.37. A one-regime survival correction would inflate board odds to 0.545; it was rejected with evidence. If post-2024 is only slow exposure, our odds are too low.
    4. The growth effect in the value model has decayed to zero (full-sample +0.05 ± 0.47). It improved early-era walk-forward but destroyed rank stability, so it is not shipped.
    5. Holdout is only 15 comps, 6 extreme (rain 400×, obol 0.0006×). One comp crossing the median moves ×4.98 materially; ex-extreme ×3.82.
    6. v4 over v3 is small, statistically. LOO (+0.021) and holdout (+0.053) gains sit inside bootstrap noise; only the Brier gain is solid (paired 90% CI excludes 0). v3 + one flag + one fix — not a leap.
    7. Snapshot frozen 14 Nov 2026. If the final kit ships a newer snapshot, every number here must be refit; the specification (regime cut, family-TVL rule, farm math) does not change.
